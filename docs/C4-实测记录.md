## 环境与连接

- Windows 主机使用本机 Codex CLI；语音识别与合成使用 MiniMax，不使用百炼 API。
- EasyInput V2 连接 2.4 GHz Wi-Fi；Host 已加载设备密钥，认证心跳持续增加。
- 四个槽位均绑定由 Windows 本机 Codex CLI 创建的任务。

## C4 七项验收

| # | 动作 | 结果 | 实际观察 |
| - | - | - | - |
| 1 | 按住 S1 说话后松手 | 通过 | Host 收到完整录音、识别成功，指令进入槽 1 队列。 |
| 2 | 任务运行中 | 通过 | 操作者看到最右第 5 颗灯变黄。 |
| 3 | 任务完成 | 通过 | 操作者看到最左第 1 颗灯亮起。 |
| 4 | 短按 S5 | 通过 | 听到总结；自然播完后第 1 颗灯熄灭。 |
| 5 | 播放时按住上排说话键 | 通过 | 播报立即停止，第 1 颗灯仍亮；再次短按 S5 后完整重播，灯熄灭。 |
| 6 | 连说两条指令给同一槽 | 通过 | 两条指令同时排入槽 1，完成后文本文件按顺序新增两行。第一句中的“乙”被语音识别为同音字“以”，顺序仍正确。 |
| 7 | 调旋钮、停至少 1 秒、断电重启 | 通过 | 调到 30 后停至少 5 秒，重启前后均听到音量 30。此前一次听到 60 是操作者又调过旋钮，该次读数不作为失败。 |
