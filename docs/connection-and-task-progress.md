# 连接状态与槽位任务过程

2026-10-06：工作台分别显示 Host、键盘、Codex 状态。Host 使用本地健康协议；键盘使用通过认证的心跳，12 秒过期；Codex 同时检查桌面进程与命名管道是否就绪，区分未启动、已启动但接口未就绪、已连接。检测不初始化客户端、不发送聊天消息。

每个槽位显示当前阶段，并突出流程中的录音、识别、投递、执行、总结、待听。有效认证音频帧触发录音，收齐音频/ASR 线程触发识别；输入进入持久队列后等待投递。只有运行任务的桌面投递日志记录 accepted 才显示执行中。完成记录尚未生成总结时显示正在生成总结；未听总结显示总结待听。新输入优先于已有待听总结，不将排队误报为执行。

识别阶段按槽位和采集 session 隔离，晚到的旧任务结果不会覆盖新录音。录音中断/识别失败/未入队错误明确显示；临时状态有失效时限。清除待听同时清除临时失败提示，保留活动录音。Host 不可达时清除界面上旧的阶段高亮，显示进度不可用。

验证：真实 UDP 测试覆盖篡改音频拒绝、有效帧进入录音、过短录音失败与清除；状态跟踪器覆盖旧 ASR 结果、新录音、槽位隔离、清除与超时；存储测试覆盖精确绑定与运行任务优先；心跳测试覆盖连接失效；前端测试覆盖六个阶段与三种 Codex 状态。无需新键盘固件。

界面整理：工作台新增“槽位管理”，将对话绑定、完整阶段、失败文字、重试和清除操作集中到独立页面，宽屏两列、窄屏单列。键盘总览保留键盘示意与四个简短状态卡，点击状态卡进入对应槽位管理。播报设置与固件页保持独立。
