# 清除待听队列

VoxQueue 每个槽位标题旁新增“清除待听”按钮。点击后将该槽位对应聊天的待听总结标记为已读，更新界面和设备信箱的待听灯状态。其他聊天的队列保留，无需逐个播放已经看过的内容。

本操作作用于当前已收集的完成记录：未发布的旧总结领取会失效，待生成内容会记入已读覆盖记录，避免后台再次合成相同总结。正在播放的一段可以继续播完；清除后播放租约的完成或取消回调不会恢复旧提示。新完成的任务仍会正常生成总结和亮灯。

语音任务继续按原 FIFO 执行。聊天记录和槽位绑定保留，未绑定聊天的待听内容保留。清除结果持久化，重启不会恢复被清除的旧待听项。重复点击不会创建新的空总结。若同一聊天绑定多个槽位，它们共享同一个待听队列；点击期间绑定变化则拒绝旧请求。
