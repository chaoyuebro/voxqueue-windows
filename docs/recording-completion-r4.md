# r4 录音完成修复（2026-10-06）

## 问题与修复

音频发送任务在等待采集队列之前读取运行状态。若用户在等待期间松开按键，采集任务可能已正常结束，而发送任务仍沿用旧状态，将其误判为 mic_read_failed，不发送 EIAE。Host 收到音频却没有结束信号，最终显示“录音未完成”。

r4 在收到采集完成信号后、持有锁时重新检查当前 generation 的停止原因。仅 client_stop 和 max_duration 被认定为正常结束。等待期间到达的最后一帧会继续发送，随后发送认证结束包；真实 I2S 故障仍保留失败处理。
